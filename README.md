# Kingsales App 🚀

O **Kingsales App** é uma aplicação voltada para a automação e gestão de força de vendas. Desenvolvido para otimizar processos comerciais, o sistema ajuda a monitorar vendas, organizar dados de clientes e melhorar o desempenho de equipes em campo.

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando as seguintes linguagens e ferramentas:

*   **Backend:** Python (Flask/Django) para inteligência de negócios e rotas.
*   **Frontend:** HTML5, CSS3 e JavaScript para uma interface responsiva e dinâmica.
*   **Controle de Versão:** Git e GitHub.

---

## 📁 Estrutura Básica do Projeto

*   `app/`: Pasta principal com as regras de negócio, rotas e visões do sistema.
*   `config.py`: Arquivo de configurações globais da aplicação.
*   `requirements.txt`: Lista de dependências e bibliotecas Python necessárias.
*   `run.py`: Arquivo principal para inicialização do servidor local.

---

## 🚀 Como Executar o Projeto Localmente

1. **Clone o repositório:**
   ```bash
   git clone https://github.com
   ```

2. **Entre na pasta do projeto:**
   ```bash
   cd kingsales-app
   ```

3. **Instale as dependências:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Execute a aplicação:**
   ```bash
   python run.py
   ```
